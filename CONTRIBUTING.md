# Contribuer à JDA

Merci de votre intérêt pour JDA.

## Comment contribuer ?

### 1. Forker le projet

Créez une copie du dépôt dans votre compte GitHub.

### 2. Créer une branche

Exemple :

```bash
git checkout -b feature/nouvelle-fonction
```

### 3. Développer votre contribution

Respectez les standards du projet.

### 4. Effectuer un commit

```bash
git commit -m "Ajout nouvelle fonctionnalité"
```

### 5. Envoyer une Pull Request

Décrivez clairement votre contribution.

## Types de contributions

- Développement
- Design UI/UX
- Documentation
- Traduction
- Tests
- Marketing digital

## Reconnaissance

Tous les contributeurs seront reconnus comme Contributeurs Bêta JDA.
